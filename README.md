# Password Cracking Labs – JTR & Networkwalks

## Overview

This repository documents practical cybersecurity labs focused on password recovery and password security in controlled training environments.

The activities covered two different approaches to password recovery:

- Password cracking using John the Ripper (JTR) and Johnny.
- Password recovery using Networkwalks Hash Calculator and Password Cracker.

## PM1 – Password Cracking with JTR

### Objective

The objective of this lab was to recover the password of password-protected PDF files using John the Ripper (JTR) and the Johnny graphical interface.

### Tools Used

- John the Ripper (JTR)
- Johnny GUI
- Windows PC
- PDF hash extraction tool

### Process

1. Downloaded and configured John the Ripper.
2. Installed and configured the Johnny GUI.
3. Located and configured `john.exe`.
4. Extracted the hash from the password-protected PDF.
5. Saved the hash in a text file.
6. Loaded the hash into Johnny.
7. Started the password recovery process.
8. Used the recovered password to open the PDF.

### Results

The practical exercise was successfully completed on three lab-provided PDF files.

## PM2 – Password Cracking with Networkwalks Tools

### Objective

The objective of this lab was to understand password recovery using Networkwalks' browser-based security tools.

### Tools Used

- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web browser
- Password-protected PDF

### Process

1. Downloaded the lab-provided password-protected PDF.
2. Uploaded the PDF to the Hash Calculator.
3. Extracted the PDF hash.
4. Copied the complete hash value.
5. Submitted the hash to the Password Cracker.
6. Waited for the password recovery process to complete.
7. Used the recovered password to open the PDF.

## Skills Practiced

- Password hash extraction
- Password recovery concepts
- John the Ripper
- Johnny GUI
- Working with PDF password hashes
- Dictionary-based password recovery
- Understanding password strength
- Cybersecurity laboratory procedures

## Ethical Considerations

All activities documented in this repository were performed using lab-provided files in a controlled learning environment.

The recovered passwords and sensitive information are not published in this repository.
